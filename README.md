## ✨ Features

- **Animated particle canvas** — floating code snippets and connected particle network in the background
- **Smooth slide navigation** — scroll, keyboard arrows (←→), and clickable nav dots
- **Progress bar** — top-of-page scroll progress indicator
- **Scroll reveal animations** — cards and list items animate in on scroll
- **Counter animations** — numeric stats count up when scrolled into view
- **Typewriter effect** — hero subtitle types out on load
- **Particle burst** — visual effect on Prev/Next button clicks
- **Glitch effect** — title text glitch animation
